# RestaurantManager-CS151-Fall-2026
Restaurant Manager (CS151 Fall 2026 - Project 2)

Overview
Our Restaurant Manager simulates the daily operations of a restaurant. Users can seat parties manage reservations, build menus, take and submit orders, manage employees, and generate receipts.
